# FlareQuorum submission pack

This folder contains copy-ready answers for the Flare Summer Signal submission.
Its field order follows the reference DoraHacks package, but every claim comes
from FlareQuorum's verified Coston2 V2 manifest, generated bindings, sanitized
evidence, and current product boundary.

## Start here

1. Use [`FLAREQUORUM-DORAHACKS-FORM.md`](FLAREQUORUM-DORAHACKS-FORM.md) for
   field-by-field form answers.
2. Use [`FLAREQUORUM-BUIDL-DETAILS.md`](FLAREQUORUM-BUIDL-DETAILS.md) for the
   long project description.
3. Open [`FLAREQUORUM-BUIDL-DETAILS-COPY.html`](FLAREQUORUM-BUIDL-DETAILS-COPY.html)
   in a browser, press `Ctrl+A`, then `Ctrl+C`, and paste into the submission
   rich-text editor to preserve headings, links, bold text, and lists.
4. Use [`FLAREQUORUM-X-SUBMISSION.md`](FLAREQUORUM-X-SUBMISSION.md) if an
   official social post or thread is requested. The published submission is
   <https://x.com/nehuutrung/status/2088033753595814272>.
5. Keep [`README.md`](README.md),
   [`NEW-WORK-LEDGER.md`](NEW-WORK-LEDGER.md), and
   [`PRIVACY-TRUST-TALK.md`](PRIVACY-TRUST-TALK.md) available as the technical
   judge package.
6. Upload [`flarequorum-logo.png`](flarequorum-logo.png), the square submission
   logo.

## Final checks

- Replace every value enclosed in `[SQUARE BRACKETS]`.
- Test the app, video, Auditor route, repository, explorer links, and X post
  while signed out.
- Keep both selected bounties and make Confidential Compute Apps primary in the
  prose.

  and non-mainnet limitations.

  redemption payout, verified service delivery, external validation, audit,
  partnership, adoption, or traction.
- Never upload bid plaintext/ciphertext, credentials, wallet or TEE keys, raw
  signatures forbidden by policy, or authenticated provider responses.
